# Antero Resources

> Antero Resources Corporation (NYSE: AR, SEC CIK 0001433270) is an independent
> oil and natural gas company exploring for, developing and producing natural
> gas, NGLs and oil in the Appalachian Basin — the Marcellus and Utica Shale of
> West Virginia and Ohio. It is one of the largest natural gas and NGL producers
> in the United States. It is NOT a software company: it publishes no developer
> program, no API, no SDK and no machine-readable service contract.

## What an agent can and cannot do here

- There is **no Antero Resources API**. As of 2026-09-02 no OpenAPI, AsyncAPI,
  GraphQL, gRPC, WSDL, MCP server or A2A agent card is served on any Antero
  host. `/openapi.json`, `/swagger.json`, `/api-docs`, `/llms.txt` and every
  named `/.well-known/` path return HTTP 404 on www.anteroresources.com.
- The only machine-readable surface carrying Antero data is **SEC EDGAR**,
  operated by the U.S. Securities and Exchange Commission — not by Antero.
- Everything Antero itself publishes is a web page, a PDF, or an RSS feed.

- [EDGAR full-text search](https://efts.sec.gov/LATEST/search-index?q=%22antero+resources%22):
  Elasticsearch-shaped JSON over filing text. HTTP 200.
- [EDGAR API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)
  and [Accessing EDGAR Data](https://www.sec.gov/os/accessing-edgar-data).

### Access rules for those endpoints (SEC policy, not Antero's)

- Max request rate: **10 requests/second** per the SEC's published fair-access policy.
- A descriptive `User-Agent` header identifying the caller is **required** on every
  request (e.g. `Sample Company Name admin@example.com`); requests without one may be blocked.
- Filings are immutable once published — cache them and poll the submissions index
  daily rather than per filing.
- See `rate-limits/antero-resources-rate-limits.yml` in this repo.
